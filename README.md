# Radar-Acessibilidade-Gov
Projeto de banco de dados relacional para monitorar a qualidade e a acessibilidade digital de todos os serviços públicos do país (disponíveis no portal Gov.br). O objetivo principal é cruzar a opinião do cidadão comum com uma auditoria técnica rigorosa baseada no padrão e-MAG (Modelo de Acessibilidade em Governo Eletrônico).
